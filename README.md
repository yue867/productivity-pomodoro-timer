# 生活效率工具箱

多功能效率工具工作台，包含番茄钟和待办事项管理两大核心功能，帮助你提高专注力并有效管理日常任务。

## 功能特点

### 🍅 番茄钟
- 倒计时显示 (MM:SS格式)
- 开始/暂停/重置控制
- 专注模式 (25分钟) -> 短休息 (5分钟) -> 专注循环
- 每4个番茄后长休息 (15分钟)
- 番茄计数（今日完成数）
- 自定义时长设置（专注、短休息、长休息时长可调）
- 提示音提醒
- 数据本地存储，跨会话保持

### ✓ 待办事项管理
- 添加/完成/删除待办事项
- 全部/待完成/已完成筛选
- 实时统计（总数、已完成数）
- 数据本地持久化存储
- 空状态友好提示

### 📤 数据导出
- 支持 JSON 格式导出
- 支持 CSV 格式导出
- 包含番茄钟数据和待办事项数据

### ✨ 视觉与动效
- Tab 标签页平滑切换动画
- 按钮点击缩放反馈
- 待办事项添加滑入动画
- 待办事项删除滑出动画
- 设置面板展开/折叠动画
- Toast 操作反馈提示

### 📱 响应式设计
- 完美支持移动端访问
- 自适应不同屏幕尺寸
- 触控友好的交互体验

## 技术栈

- HTML5
- CSS3 (Soft UI 风格 + 动效)
- 原生 JavaScript (ES6+ 模块化类设计)
- Web Audio API (提示音)
- Iconify API (图标资源)
- localStorage (数据持久化)

## 工具架构

| 工具 | 数据存储 Key | 功能边界 |
|------|-------------|----------|
| 番茄钟 | `pomodoroSettings`, `pomodoroCount`, `pomodoroDate` | 专注计时、番茄计数、设置管理 |
| 待办事项 | `todoItems` | 待办增删改查、状态切换、筛选 |
