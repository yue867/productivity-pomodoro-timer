# 专注番茄钟

基于番茄工作法的专注计时工具，帮助你提高工作效率。

## 功能特点

- 倒计时显示 (MM:SS格式)
- 开始/暂停/重置控制
- 专注模式 (25分钟) -> 短休息 (5分钟) -> 专注循环
- 每4个番茄后长休息 (15分钟)
- 番茄计数（今日完成数）
- 自定义时长设置（专注、短休息、长休息时长可调）
- 提示音提醒
- 数据本地存储，跨会话保持
- 响应式设计，支持移动端

## 使用方法

1. 在输入框中输入当前任务名称（可选）
2. 点击"开始"按钮启动计时器
3. 专注时间结束后会自动切换到休息模式
4. 点击"暂停"可暂停计时，点击"重置"可重新开始当前阶段

## 设置选项

- **专注时长**: 1-60分钟，默认25分钟
- **短休息时长**: 1-30分钟，默认5分钟
- **长休息时长**: 1-60分钟，默认15分钟
- **长休息前番茄数**: 2-10个，默认4个
- **提示音**: 开启/关闭
